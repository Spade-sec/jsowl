# 实现静态可折叠 API 提取（astapi.go 五项扩展）

## 目标
在 `internal/discover/astapi.go` 补齐五类静态可折叠场景：`new URL` 构造、三元表达式、对象字面量成员访问、`replace` 字符串方法、`atob` 解码。全部是局部改动，不动 pipeline 与数据结构。

## 改动明细

### 1. `new URL(path, base)` 构造
- `walk` 新增 `new_expression` 分发 → `visitNewExpression`：构造器为标识符 `URL` 或 `window.URL`（member/subscript 均可）时，折叠 args（`foldConcat`/`templatePlaceholder`）：
  - path 以 `http(s)://` 开头 → 直接取 path；
  - 双参数且 path 以 `/` 开头 → 取 base 的 origin 部分拼 path（简单 join，不做完整 URL 解析）；否则 base+path 直拼。
- `bind`（astapi.go:204-218）扩展：`const u = new URL(...)` 的声明值也折叠成字符串存入 `constants`，使 `fetch(u.href)` 可解析。
- `resolveURLExpression` 新增 `member_expression` 分支：object 是 constants 命中的标识符（`.href`/`.toString()` 等尾缀忽略）→ 返回常量值。

### 2. 三元表达式 → 双分支候选（recall 优先）
- 新增 `resolveURLExpressions`（复数）：`conditional_expression` 时对 consequent 和 alternative 各自递归解析，返回多值（去重）；其他节点退化为单值。
- `visitCall`（astapi.go:345-352）把单次 `resolveURLExpression` 改为遍历多值，每个 raw 产出一条 Candidate（method/body 参数提取不变，同一调用点最多两条 URL）。

### 3. 对象字面量成员访问
- 新增 `objectConstants map[string]map[string]string`：`bind` 遇到声明值为 `object` 字面量时，抽取字符串键值对存入。
- `resolveURLExpression` 新增分支：`routes.users`（member）与 `routes["users"]`（subscript，index 为 string）→ 查 `objectConstants` 返回值。
- 同时让 `bind` 支持 `template_string` 声明值（经 `templatePlaceholder` 存 `"x/{}"`），与现有占位符语义一致。

### 4. `replace` / `replaceAll`
- `foldConcat` 的 `call_expression` 分支（约 L800 附近）加 case：receiver 与两个参数各自折叠（失败降级 `{}`），执行 `strings.ReplaceAll`。

### 5. `atob` 解码
- 新增小工具 `decodeBase64String`（std + URL-safe 两种编码，容忍空白，失败返回空）。
- `foldConcat` 与 `resolveURLExpression` 识别 `atob` / `window.atob` 单字符串参数调用，成功解码后按 `evidenceFor(解码值)` 赋 evidence。

## 顺序
1 → 3 → 5 → 4 → 2（2 涉及 visitCall 循环化，放最后）。

## 测试（astapi_test.go，沿用 astCandidates/findCandidate 模式）
- `new URL("/users", base).href` → `/BASE/users` 类结果；`fetch(u.href)` 经常量绑定可提。
- 三元：`fetch(flag ? "/api/a" : "/api/b")` → 两条候选都存在。
- `routes.users` 与 `routes["users"]` → `/u/list`。
- `"/api/v1/x".replace("v1","v2")` → `/api/v2/x`。
- `fetch(atob("L2FwaS91c2Vycw=="))` → `/api/users`，evidence 断言。
- 现有 451 行测试回归通过；全程 `go test ./...` 验证。

## 不做（明确排除）
- `split(x)[i]`（需下标-求值联动，单独做）、`process.env`/运行时配置（browser 模式职责）、过程间参数传播（另一个量级）。

预计改动集中在 astapi.go 约 150 行 + 测试约 80 行。
